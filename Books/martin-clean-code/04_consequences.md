# Чистый код: Слой СЛЕДСТВИЯ

---

## I-001: Команда станет двигаться быстрее

Если все пишут чистый код:
- Новая фича займет меньше времени
- Багов будет меньше
- Code review станет быстрее
- Onboarding новых разработчиков проще

**Результат:** скорость увеличится в 2-3 раза в долгосроке.

---

## I-002: Качество кода улучшится резко

Плохой код ведет к большему плохому коду (破窗). Чистый код ведет к большему чистому коду.

**Результат:** качество продукта улучшится.

---

## I-003: Технический долг исчезнет

Если писать чисто с начала:
- Не будет спешных решений
- Не будет "потом переделаю"
- Не будет накопления грязи

**Результат:** проект не заболеет.

---

## App-001: Boy Scout Rule - оставляй лагерь чище

Принцип: каждый раз когда читаешь код, улучшай его немного.

**Применение:**
- Fix -> улучшение
- Feature -> refactoring
- Review -> cleanup

**Результат:** код постепенно становится чище.

---

## App-002: TDD (Test-Driven Development) как дисциплина

Писать тест ДО кода.

**Применение:**
- Сначала тест (красный)
- Потом код (зеленый)
- Потом refactoring

**Результат:** код сразу чистый, без переделок.

---

## App-003: Code Review как гарантия чистоты

Не допускать грязный код в master.

**Применение:**
- Pull Request обязателен
- Reviewer должен понимать код
- Если не понимает - то грязный

**Результат:** стандарты поддерживаются.

---

## Lim-001: Чистый код требует времени

Не получится писать чистый код быстрее, чем грязный.

**Ограничение:** сначала медленнее.

**Решение:** вкладывают в долгосроке.

---

## Lim-002: Легаси код трудно улучшить без тестов

Если нет тестов, рефакторинг опасен (можно сломать).

**Ограничение:** нужны Learning Tests перед рефакторингом.

**Решение:** писать тесты ДО рефакторинга.

---

## Lim-003: Культура не меняется сразу

Если команда привыкла к грязному коду, не привыкнет к чистому за неделю.

**Ограничение:** нужна дисциплина.

**Решение:** начинать с малого, постоянно улучшать.

---

## Резюме СЛЕДСТВИЙ

**Если писать чистый код:**
- Быстрее разрабатывать
- Меньше багов
- Лучше поддерживать
- Счастливей команда

**Если писать грязный код:**
- Быстро сейчас
- Медленно потом
- Команда застревает в болоте

**Выбор:** инвестировать сейчас или платить потом (10:1).
