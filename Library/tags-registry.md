## Как читать этот реестр

| Колонка | Значение |
|---------|----------|
| **Тег** | kebab-case на русском (напр., #архитектура) |
| **Определение** | Одна строка — что это означает в контексте |
| **Используется в** | Какие книги используют этот тег |
| **Кол-во** | В скольких книгах встречается |
| **Страница концепции** | Есть ли concepts/*.md для этого тега |

## Условные обозначения

- **CA** = Clean Architecture
- **Ideal** = Идеальная работа (The Clean Coder)
- **Pragmatic** = Идеальный программист (The Pragmatic Programmer)
- **Parallel** = Модели параллельного программирования
- **Code** = Код, который умещается в голове (Code That Fits in Your Head)

## Примеры пересечений

- Clean Architecture: архитектура как набор решений

- Pragmatic Programmer: архитектура как стратегия долгосрочного развития
- Parallel Programming: архитектура как выбор модели параллелизма

### Пример 2: #простота (4 книги)
- Clean Architecture: простота как следствие хорошей архитектуры
- Code That Fits: простота как стратегия для когнитивной нагрузки
- Pragmatic Programmer: простота как профессиональный выбор
- Ideal Work: простота как проявление мастерства

### Пример 3: #параллелизм (3 книги)
- Parallel Programming Models: параллелизм как выбор модели (locks, actors, immutability)
- Clean Architecture: параллелизм как следствие хорошего дизайна
- Code That Fits: параллелизм как сложность для когнитивной нагрузки

## Процесс обновления

**Текущий (v1.0, вручную):**
1. Когда добавляю новую книгу, вручную смотрю её теги
2. Вношу в этот реестр новые теги
3. Обновляю counts
4. Создаю новые файлы в concepts/

**Будущий (v2.0, автоматизировано):**
1. Запускаю `./build-library.sh`
2. Скрипт читает все Books/*/0*.md
3. Вытаскивает все #теги автоматически
4. Обновляет этот файл
5. Генерирует или обновляет concepts/*.md
6. Добавляет перекрёстные ссылки
