## 💡 Key Insights

1. **Different Goals = Different Designs**

   - GitHub: "Help developers follow standards"

   - Local: 80+ nodes of analysis (17% coverage of 464 pages)
   - GitHub: Condensed to 3 files (30% of nuance lost)

3. **Teaching vs Enforcement**
   - Local: "Here's why. Now you decide."
   - GitHub: "Here's the rule. Now apply it."

4. **The Real Difference**
   - Local explains WHY (builds judgment)
   - GitHub prescribes WHAT (enables compliance)
